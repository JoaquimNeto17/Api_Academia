🏋️‍♂️ API Academia (Back-end)

Vercel: https://api-academia-mu.vercel.app/

API desenvolvida para gerenciamento de atletas de academia, permitindo cadastro, autenticação e controle de usuários via CPF.

📌 Sobre o Projeto

A API Academia é o back-end responsável por fornecer dados e regras de negócio para o sistema de gestão de academia.

Ela permite registrar atletas, validar acessos e manipular informações de forma estruturada, podendo ser integrada a aplicações front-end.

💡 Ideal para projetos full stack, testes de API e integração com sistemas web.

🎯 Funcionalidades

✔️ Cadastro de atletas
✔️ Autenticação de usuários
✔️ Validação de CPF
✔️ Listagem de registros
✔️ Atualização de dados
✔️ Remoção de usuários
✔️ Estrutura baseada em API REST
